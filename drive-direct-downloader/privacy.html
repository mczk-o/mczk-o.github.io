Drive Direct Downloader（Chrome 拡張機能） / 最終更新日: 2026年11月13日

1. この拡張機能が行うこと

Drive Direct Downloader は、Google Drive のファイルを、複数の zip に分割されることなくお使いのパソコンに直接ダウンロードするための拡張機能です。

2. アクセスする情報

ダウンロードを行うために、Google アカウントの認証（OAuth）を通じて、利用者が許可した範囲で Google Drive のファイルおよびフォルダの情報（名前、構成、内容）にアクセスします。

3. 情報の利用目的

アクセスした情報は、利用者が指定したファイルをダウンロードする目的にのみ使用します。それ以外の目的（広告、分析、AI の学習など）には使用しません。

4. 情報の保存・共有

ファイルは Google Drive から利用者のブラウザへ直接ダウンロードされます。開発者は、利用者のファイル、Google アカウント情報、その他の個人情報を収集・保存せず、第三者に販売・提供・転送することもありません。認証情報（アクセストークン）は利用者のブラウザ内でのみ扱われます。

5. Google API サービスのユーザーデータに関するポリシー

本拡張機能による Google API から取得した情報の使用は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に準拠します。

6. アクセス権の取り消し

利用者は、Google アカウントの設定からいつでも本拡張機能のアクセス権を取り消すことができます。拡張機能を削除すると、ブラウザ内のデータも削除されます。

7. ポリシーの変更

本ポリシーを変更する場合は、このページでお知らせします。

8. お問い合わせ

本ポリシーに関するお問い合わせは GitHub Issues までお願いします。
